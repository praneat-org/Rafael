## หน้า 1

Architecture
Lumora Desk ทำงานบน cloud region กรุงเทพฯ (ap-southeast-7) ข้อมูลลูกค้าไทยไม่ออกนอกประเทศ
รองรับ 10,000 tickets ต่อชั่วโมงต่อ tenant · REST API rate limit 600 requests ต่อนาที · มี webhook

## หน้า 2

Security และ Integration
- SSO: SAML 2.0 และ OIDC (Okta, Azure AD, Google Workspace) · รองรับ MFA
- เข้ารหัส AES-256 at rest และ TLS 1.3 in transit
- Certification: ISO 27001 และ SOC 2 Type II · สอดคล้อง PDPA
- Integrations: LINE OA, Facebook Messenger, email, Salesforce, Slack, Zapier

## หน้า 3

Data
เก็บประวัติ ticket 24 เดือน (ค่าเริ่มต้น) · audit log 12 เดือน · export เป็น CSV หรือ JSON
UI ภาษาไทย อังกฤษ ญี่ปุ่น · ไฟล์แนบสูงสุด 25 MB ต่อไฟล์
