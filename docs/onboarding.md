# Rafael: คู่มือใช้งาน 1 หน้า (AE / PM)

Rafael ฟังการประชุมของคุณแล้วขึ้นคำตอบจากเอกสาร deal ให้ทันที (สูงสุด 3 ข้อ พร้อมที่มา [ไฟล์ › หน้า]) ใช้ได้กับ Chrome บนคอมพิวเตอร์เท่านั้น ไม่ต้องติดตั้งอะไร เปิดลิงก์ที่ทีมแจ้งแล้วเริ่มได้เลย

## 0. แจ้งลูกค้าก่อนเริ่มทุกครั้ง

- ก่อนกดเริ่ม ให้พูดกับลูกค้าที่ต้นประชุม (ทุกครั้ง ถ้าเข้าประชุมสาย ให้แจ้งก่อนกดเริ่ม)
- ประโยคที่ใช้: "ในการประชุมนี้ ทีมของเรามีระบบช่วยฟังเพื่อค้นหาข้อมูลจากเอกสารของเราเอง ระบบของเราไม่เก็บไฟล์เสียงหรือข้อความการสนทนาไว้หลังจบการประชุม โดยเสียงและข้อความจะถูกประมวลผลโดยผู้ให้บริการภายนอกตามเงื่อนไขของผู้ให้บริการ หากไม่สะดวก แจ้งได้เลยครับ/ค่ะ ทีมงานของเราจะปิดระบบให้"
- ถ้อยคำนี้ยังเป็นร่าง รอ DPO ยืนยัน (ดู docs/privacy/dpo-brief.md) ถ้ามีฉบับใหม่ให้ใช้ฉบับใหม่
- ลูกค้าไม่สะดวก หรือคัดค้านเมื่อไรก็ตาม: กดจบ session ทันที
- ห้ามใช้เมื่อ: ลูกค้าไม่ยินยอม, ประชุมลับภาครัฐ, คาดว่าจะมีข้อมูลส่วนบุคคลอ่อนไหว (สุขภาพ ศาสนา ชีวภาพ ประวัติอาชญากรรม), สัญญา/NDA ห้ามใช้ AI หรือผู้ประมวลผลภายนอก, ลูกค้าต้องการให้ข้อมูลอยู่ในไทย

## 1. เริ่ม session

- เปิดลิงก์ Rafael ด้วย Chrome บนคอมพิวเตอร์ (มือถือหรือเบราว์เซอร์อื่นจะขึ้นข้อความเตือน)
- กด "ลงชื่อเข้าใช้ด้วย Google" แล้วเลือกบัญชี @praneat.com (บัญชีอื่นจะใช้ไม่ได้ กด "เปลี่ยนบัญชี" เพื่อเลือกใหม่)

## 2. เลือกแหล่งเอกสาร (โฟลเดอร์ Drive)

- วางลิงก์โฟลเดอร์ Google Drive ของ deal ในช่อง "โฟลเดอร์เอกสารของ deal" (ต้องเป็นลิงก์โฟลเดอร์ ไม่ใช่ไฟล์) หรือกดเลือกจากโฟลเดอร์ล่าสุด
- Rafael อ่านไฟล์ด้วยสิทธิ์ Drive ของคุณเอง โฟลเดอร์ที่คุณเปิดไม่ได้ก็อ่านไม่ได้
- ใส่ชื่อผู้เข้าร่วมประชุมได้ (ไม่บังคับ ใช้ในสรุปการประชุม)

## 3. อนุญาตเสียง

- ติ๊ก "เสียงจากแท็บ Meet" เพื่อให้ Rafael ได้ยินลูกค้า และ/หรือ "ไมค์ในห้องประชุม" (ติ๊กอย่างน้อย 1 อย่าง)
- กด "เริ่ม session" Chrome จะถามให้เลือกแท็บ: เลือกแท็บ Meet (แท็บ ไม่ใช่หน้าต่างหรือทั้งจอ) และติ๊ก **"แชร์เสียงแท็บ" (Also share tab audio)** ที่มุมล่างของหน้าต่างเลือก ถ้าไม่ติ๊ก Rafael จะไม่ได้ยินลูกค้า
- กดอนุญาตไมค์เมื่อ Chrome ถาม
- ระหว่างประชุมเปิดหน้า Rafael ทิ้งไว้ในแท็บของมัน (ห้ามปิดแท็บ ถ้าปิดจะจบ session และ log หาย)

## 4. ระหว่างประชุม

- cue ขึ้นเมื่อลูกค้าถาม พร้อมที่มา [ไฟล์ › หน้า] ที่ตรวจได้
- ถ้าขึ้น "ไม่พบใน pack" แปลว่าเอกสารไม่มีคำตอบ อย่าเดา เก็บไว้ตามต่อ
- พิมพ์ถามเองได้ในช่องข้อความ กด Pause เมื่อมีช่วงที่ไม่ควรให้ฟัง

## 5. จบ session

- กด "จบ session" เมื่อประชุมจบ (หรือเมื่อลูกค้าขอให้ปิด)
- หน้าจบแสดงรายการที่ต้องตามต่อ

## 6. ดาวน์โหลดและสรุป

- ดาวน์โหลด Conversation Log ได้เป็น .md, PDF หรือ .json ทันที Rafael ไม่เก็บ log ไว้ที่ใด ถ้ากดลบก่อนดาวน์โหลดจะกู้คืนไม่ได้
- กด "สร้างสรุป" เพื่อได้ร่างสรุปการประชุม (ประมาณ 1 นาที) แก้ไขในช่องได้ แล้วคัดลอกหรือดาวน์โหลดเป็น .md / PDF
- เสร็จแล้วกด "ลบ session แล้วเริ่มใหม่"

## 7. ส่งความเห็น

- กดปุ่ม "ส่งความเห็นเกี่ยวกับ Rafael" ที่หน้าจบ session (เปิดฟอร์มในแท็บใหม่) บอกได้เลยว่าอะไรช่วยหรือไม่ช่วย
- ถ้าไม่มีปุ่ม แจ้งทีมพัฒนา Rafael โดยตรง
